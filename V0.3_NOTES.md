# v0.3 implementation notes

- Structured boards store six selected Batomon names as a ` · `-separated local field. This is intentionally text-only and remains editable through the selectors.
- History summaries group completed runs by opening-board string and calculate observed round wins from manually entered `W`/`L` results. They are personal observations, not forecasts.
- The Comps tab opens the current public tier list and team-builder pages in the user's browser. The APK still requests no Internet permission.
- The four catalogs are fetched from public server-rendered routes by `tools/fetch_reference_catalogs.py`; the generator validates minimum record counts and writes only text metadata.
- Remote sprite paths are provenance only. No game art is bundled because public licensing is not clear.
