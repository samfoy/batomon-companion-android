# v0.3.0 release

This is the first durable release-signed APK. The signing identity is retained outside the repository under `/home/sam/.config/batomon-companion-android/` and mirrored to the four GitHub Actions secrets documented in `RELEASE_SIGNING.md`.

The v0.2.0 APK was debug-signed, so Android will reject an in-place update from v0.2.0. Uninstall v0.2.0 before installing v0.3.0; its local Room database is removed with the uninstall.
